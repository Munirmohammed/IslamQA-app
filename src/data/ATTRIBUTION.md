# Third-party data in this directory

## azkar.json

Source: [my-prayers/muslim-data-android](https://github.com/my-prayers/muslim-data-android)
License: Apache License 2.0

Extracted from that project's bundled `muslim_db_v2.5.1.db` SQLite database
(the `azkar_*` tables -- categories, chapters, items, English translations,
and references), re-shaped into a flat JSON structure for this app. No
other fields or tables from that database are used here.

A copy of the Apache 2.0 license text is available at
https://github.com/my-prayers/muslim-data-android/blob/main/LICENSE.
